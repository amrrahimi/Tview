# TradingView AutoBot (Windows)

ربات دسکتاپ که روی چارت باز TradingView:
1. با **START** چارت را از روی صفحه می‌خواند (رنگ کندل‌ها) و تشخیص می‌دهد بازار **روندی (صعودی/نزولی)** است یا **رنج**.
2. کنترل موس و کیبورد را می‌گیرد، با کلید `/` بخش **Indicators** را باز می‌کند و اندیکاتور مناسب را جستجو و اضافه می‌کند (روندی: Supertrend، رنج: Bollinger Bands).
3. یک اسکریپت Pine با **تنظیمات محاسبه‌شده از تحلیل** در Pine Editor می‌نویسد و Add to chart می‌کند تا برچسب‌های **BUY / SELL** روی چارت نمایش داده شوند (alert هم دارد).
4. در حالت مانیتور، هر N ثانیه دوباره چارت را تحلیل می‌کند و اگر رژیم بازار عوض شد، استراتژی را عوض می‌کند.
5. با **ESC** از حالت اتومات خارج می‌شود. (بردن موس به گوشه صفحه هم توقف اضطراری است.)

## ساخت EXE با GitHub
1. یک ریپازیتوری جدید بساز و همه فایل‌ها (شامل پوشه `.github`) را push کن.
2. تب **Actions** → workflow «Build Windows EXE» خودکار اجرا می‌شود (یا Run workflow).
3. از بخش **Artifacts** فایل `TradingViewAutoBot.exe` را دانلود کن.
4. اگر تگ `v1.0` بزنی، EXE در بخش Releases هم منتشر می‌شود.

## اجرای مستقیم (بدون EXE)
```
pip install -r requirements.txt
python main.py
```

## اولین اجرا
1. چارت TradingView را در مرورگر باز و **Maximize** کن (تم و رنگ کندل پیش‌فرض).
2. در ربات **Calibrate** را بزن: موس را روی دکمه Pine Editor ببر و F8، روی محل متن کد F8، روی Add to chart F8 (یا F9 برای استفاده از Ctrl+Enter).
3. **Test analysis** برای دیدن نتیجه تحلیل بدون کنترل موس.
4. **START**. برای خروج: **ESC**.

## نکات
- اگر رنگ کندل‌ها را عوض کرده‌ای، `candle_colors` را در `config.json` (کنار exe) اصلاح کن.
- اگر بعد از Calibrate، Pine Editor از قبل باز است، تیک «Pine Editor is already open» را بزن.
- این ابزار مشاوره مالی نیست؛ سیگنال‌ها را حتماً بک‌تست کن. خودکارسازی رابط کاربری ممکن است با قوانین استفاده TradingView در تضاد باشد.
